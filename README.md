# Smart RFID Gate System

Source code for a school RFID gate and student-record system.

## Project Structure

- `backend/`: Node.js API and PostgreSQL schema migrations.
- `frontend/`: React web application.
- `Admin_RFID_Scanner/`: administrative RFID scanner firmware.
- `Gate_RFID_Scanner/`: gate RFID scanner firmware.
- `firmware/`: connectivity test firmware.

Private configuration, database records, backups and internal documentation are not included in this repository.
